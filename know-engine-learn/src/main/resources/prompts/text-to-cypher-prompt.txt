# 示例
问题：BMW有哪些车型？
Cypher：MATCH (b:Brand {englishName: 'BMW'})-[:HAS_MODEL]->(m:CarModel) RETURN {`关系`: '品牌拥有车型', `品牌`: b.name, `车型`: m.name, `燃料类型`: m.fuelType, `车辆类型`: m.vehicleType} AS result

问题：宝马3系有哪些版本？
Cypher：MATCH (b:Brand {name: '宝马'})-[:HAS_MODEL]->(m:CarModel {name: '3系'})-[:HAS_VERSION]->(v:CarVersion) RETURN {`关系`: '车型包含版本', `车型`: m.name, `版本`: v.name, `指导价`: v.guidePrice, `状态`: v.status} AS result

问题：哪些车在2025年还在售？
Cypher：MATCH (v:CarVersion {status: '在售', modelYear: 2025}) RETURN {`版本`: v.name, `年款`: v.modelYear, `状态`: v.status, `指导价`: v.guidePrice} AS result

问题：宝马3系330i用了哪些配件？
Cypher：MATCH (v:CarVersion {infoId: 'CI_006'})-[:USES_PART]->(p:Part) RETURN {`关系`: '车辆版本使用配件', `车辆版本`: v.name, `配件`: p.name, `类别`: p.category, `价格`: p.price} AS result

问题：哪些车是纯电动的？
Cypher：MATCH (v:CarVersion)-[:HAS_ENERGY_TYPE]->(e:EnergyType {name: '纯电动'}) RETURN {`关系`: '车辆版本使用能源类型', `车辆版本`: v.name, `能源类型`: e.name} AS result

问题：哪些车和Model 3长续航版使用了相同的轮胎？
Cypher：MATCH (model3:CarVersion {infoId: 'CI_001'})-[:USES_PART]->(p:Part)<-[:USES_PART]-(other:CarVersion) WHERE other <> model3 AND p.category = '轮胎' RETURN {`关系`: '两个车辆版本共同使用配件', `车辆版本A`: model3.name, `车辆版本B`: other.name, `共同配件`: p.name, `配件编号`: p.partNo} AS result

问题：使用了宁德时代电池的车有哪些？
Cypher：MATCH (p:Part {name: '宁德时代三元锂电池 75kWh'})<-[:USES_PART]-(v:CarVersion) RETURN {`关系`: '车辆版本使用配件', `车辆版本`: v.name, `配件`: p.name} AS result

问题：小米 SU7 Max 与蔚来 ET5 2025 相同配件分析
Cypher：MATCH (a:CarVersion)-[:USES_PART]->(p:Part)<-[:USES_PART]-(b:CarVersion) WHERE toLower(replace(a.name, ' ', '')) = toLower(replace('小米 SU7 Max', ' ', '')) AND toLower(replace(b.name, ' ', '')) = toLower(replace('蔚来 ET5 2025', ' ', '')) RETURN DISTINCT {`关系`: '两个车辆版本共同使用配件', `车辆版本A`: a.name, `车辆版本B`: b.name, `配件编号`: p.partNo, `共同配件`: p.name, `类别`: p.category, `品牌`: p.brand, `价格`: p.price} AS result

列表、属性、关系、路径、统计查询均遵守此规则；统计结果保留统计对象、筛选范围和指标名，路径保留节点及关系顺序。保留原查询的筛选、分组、排序和去重语义，不把逐行明细混入聚合分组。缺失属性保留 null，未知单位不补写；无匹配时不得构造肯定事实（计数为 0 时如实返回）。无需 APOC。
